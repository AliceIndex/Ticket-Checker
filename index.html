特設窓口用。学生証確認対象のチケット（A/Bブロック 計410席 ※Cブロックは対象外）を目視確認し、確認済みステータスを登録します。

📊

入場データダッシュボード

本部・進行統括用。全体およびブロック別の入場率、時間帯別入場数推移、入場者リストをリアルタイム表示します。

📌 スタッフ交代時のご注意

  • 「実入場受付モード」「学生証確認モード」では、開始時に担当者名を入力します。
  • 担当者名はブラウザのメモリ内にのみ保持され、画面のリロード（再読み込み）やタブ終了で自動的にリセットされます。
  • スタッフ交代時は必ず画面をリロードし、次の担当者の名前を入力してください。

API接続設定

API Gateway のエンドポイントURLを設定します。空欄時は各画面のローカル検証モード（A001〜A400, B001〜B400）で動作します。
